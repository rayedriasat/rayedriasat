## Featured Work

### ScholarMate - Offline-first AI research workspace

[scholarmate.northsouth.app](https://scholarmate.northsouth.app/)

AI research workspace built around RAG-powered semantic search, local and cloud-synced documents, PDF workflows, Google Drive ownership, and cross-platform access.

- Built contextual querying across user documents using vector databases and RAG
- Integrated Google Drive for user-controlled storage and secure external sync
- Led and supervised two independent development teams under faculty trust
- Technical paper received Best Session Performer Award at APMEE 2025

### Pruning-SeamlessM4T - ML compression research

[Repository](https://github.com/rayedriasat/Pruning-SeamlessM4T)

Structured compression and deployment pipeline for Meta SeamlessM4T v2 multilingual speech-to-speech translation.

- Reduced parameters by 39.7%, from 1.805B to 1.088B
- Achieved 1.84x inference speedup
- Reduced VRAM usage enough for consumer hardware deployment
- Built a working FastAPI duplex web app for real-time speech translation

### KajBuzz - Intelligent academic task planner

[Live demo](https://rayed.pythonanywhere.com/) - [Repository](https://github.com/rayedriasat/intelligent_task_planner)

AI-assisted academic productivity platform that plans schedules from deadlines, priorities, availability, and learning workflows.

- Built with Django, HTMX, TailwindCSS, MySQL, Google OAuth, and OpenRouter
- Integrated Google Calendar and Canvas LMS assignment workflows
- Designed smart scheduling, overload detection, Pomodoro tracking, and analytics

### BloodConnect - Blood donation management system

[Repository](https://github.com/rayedriasat/bconnect)

Role-based donation platform connecting donors and requesters through location-aware matching and request workflows.

- Built donor registration, request creation, appointment coordination, and messaging
- Implemented compatibility and proximity-based matching
- Used PHP, MySQL, JavaScript, TailwindCSS, and Leaflet/OpenStreetMap

### RDS2vanced - Course schedule planner

[Live demo](https://rayedriasat.github.io/rdsVanced) - [Repository](https://github.com/rayedriasat/rdsVanced)

Interactive university course planner for browsing courses, building conflict-free routines, and exporting schedules.

- Added course search, conflict detection, local autosave, theme toggle, and export tools
- Designed for responsive use across desktop and mobile
